# **프로젝트 개요**

# [프로젝트명]

> 부산항 크루즈 입항 패턴 기반 사전 운영계획 검토 지원
> 

## 1. 프로젝트 기본 정보

- **프로젝트 주제:** 부산항 크루즈 입항 공공데이터를 활용하여 사전 운영계획 검토에 참고할 수 있는 기초자료 제공
- **팀명:** 가성비 한량
- **프로젝트 기간:** 2026-10-16~2026-11-09
- **주요 활용 대상:** 부산항만공사 운영본부 내 항만산업부

---

## 2. 프로젝트 배경 및 목표

- **추진 배경:** 항만 내부 운영자료 및 관계기관 협조를 얻기 어렵다는 제약 속에서 크루즈 입항 공공데이터가 어디까지 활용될 수 있는지 확인하고, 이를 항만 운영계획 검토에 참고할 수 있는 정보로 제공한다.
- **문제 정의:** 공공데이터를 활용하여 사전 운영계획 검토에 도움이 되는 자료를 어느 수준까지 도출할 수 있는지 확인한다.
- **프로젝트 목표:**
    1. 크루즈 입항 패턴과 계선장소별 특성을 분석하고, 사전 운영계획 검토에 참고할 수 있는 대시보드를 구축한다.
    2. 과거 입항 데이터를 활용한 예측모델을 구현하고, 2027년 크루즈 입항 예정 스케줄과 비교하여 예측 결과의 활용 가능성을 검토한다.

---

## 3. 활용 데이터

- **데이터 출처:** PORT-MIS
- **데이터 기간:** 2013-01~2026-10-16
- **주요 데이터 항목:** 입항일시, 승객 수, 계선장소 등
- **비교자료:** 부산항만공사 2027년 크루즈 입항 예정 스케줄

---

## 4. 주요 분석 및 구현 내용

- **주요 분석 내용:**
    1. 연도·월별 입항 패턴 및 승객 수 파악
    2. 계선장소별 입항건수 및 TOP 5 계선장소 분석
    3. 사드 및 코로나19 전후의 입항 추이 비교
- **대시보드:** Streamlit 기반 대시보드를 구현하여 주요 분석 결과를 시각화하고, 사용자가 조건에 따라 입항 정보를 조회하고 비교할 수 있도록 구성한다.
    - **주요 화면**
        1. 홈
        2. 입항 패턴 분석
        3. 계선장소 분석
        4. 과거 이력 조회
        5. 2027년 예측(Beta)
- **예측모델:**
    1. 과거 크루즈 입항 데이터를 활용하여 ETS 기반 입항건수 및 승객 수 예측모델을 구현하고, 예측 결과와 모델의 오차를 검토한다.
    2. 예측 오차율(WAPE)의 목표 기준은 20% 이하로 설정하며, 5%p를 추가 허용하여 25% 이하까지 허용 범위로 판단한다.
- **사용 기술:**
    
    
    | 구분 | 사용 라이브러리 및 플랫폼 | 활용 목적 |
    | --- | --- | --- |
    | 프로그래밍 | Python | 데이터 분석 및 앱 개발 |
    | 데이터 처리 | Pandas, NumPy | 데이터 전처리 및 집계 |
    | 시각화 | Plotly | 분석 결과 시각화 |
    | 웹 애플리케이션 | Streamlit | 대시보드 및 예측모델 앱 구현 |
    | 예측모델 연구 | Statsmodels | 예측모델 구현(ETS) |
    | 버전 관리 | GitHub | 프로젝트 코드 및 결과물 관리 |

## 7. 프로젝트 한계 및 참고사항

- **데이터의 한계:** 공공데이터를 활용하므로 항만 내부 운영정보와 외부 변수를 충분히 반영하기 어렵다. 또한 월 단위 분석에 초점을 맞추어 일자·요일별 입항 집중도는 제공하지 않는다.
- **구현 및 검증의 한계:** 2027년 예정 스케줄의 승객 정원수는 실제 승객 수가 아니므로, 예측결과 그대로 사전 운영계획에 적용하기에는 보완이 필요하다.(입항건수 예측도 동일)
- **참고사항:** 대시보드와 예측모델은 사전 운영계획 검토를 위한 참고정보 제공을 목적으로 하며, 실제 항만 운영계획을 직접 수립하거나 기존 운영 시스템을 대체하지 않는다.
